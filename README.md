# 📊 Customer Dashboard

![Customer Dashboard](./Photos/Customer%20Dashboard.png)

> **وصف المشروع:** لوحة تحكم تفاعلية لتحليل بيانات العملاء (Customer Dashboard) تهدف إلى تتبع سلوكيات العملاء، قياس مؤشرات الأداء الرئيسية (KPIs)، وتسهيل اتخاذ القرارات التجارية بناءً على البيانات.

---

## 🚀 المميزات الرئيسية (Features)
- 👥 **تحليل سلوك العملاء:** تتبع تفاصيل وتفضيلات العملاء بشكل مرئي.
- 📈 **مؤشرات الأداء (KPIs):** عرض الإحصائيات الحيوية مثل معدل الاحتفاظ بالعملاء والقيمة الدائمة (LTV).
- 📉 **رسوم بيانية تفاعلية:** مقارنة وتحليل البيانات عبر فترات زمنية مختلفة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **أداة التحليل:** Power BI / Tableau / Excel (أو الفรมوورك المستخدم)
- **معالجة البيانات:** Python / SQL (حسب الحاجة)
